# LumaSense 사용 안내

## 실행과 모니터 선택

Windows 11에서 ZIP을 풀고 `LumaSense` 폴더 전체를 보관한 채 `LumaSense.exe`를 실행한다.<br>
`_internal` 폴더에는 Qt와 Python 실행에 필요한 파일이 들어 있다.<br>
Twinkle Tray는 별도로 설치하고 모니터의 DDC/CI를 활성화한다.<br>
LumaSense가 Twinkle Tray의 명령행 기능을 사용하므로 밝기를 제어하는 동안 Twinkle Tray를 실행해 둔다.<br>
일반모드에서는 `연결 / 상태`의 `모니터 선택 / 탐색`에서 밝기를 바꿀 모니터를 선택한다.<br>
Twinkle Tray 경로를 직접 지정하거나 API를 시험하려면 고급모드의 `수동 모니터 시험`을 연다.<br>
밝기는 선택한 모니터에 적용되며 화면 절전은 연결된 화면 전체에 적용된다.<br>
창 닫기는 트레이로 숨기며 `종료` 버튼이나 트레이 메뉴로 종료한다.<br>
트레이 아이콘을 더블클릭하거나 트레이 메뉴의 `설정 / 시험 창 열기`를 누르면 창을 복원해 다른 창 앞으로 가져온다.<br>
최대화 상태는 유지하며 최소화된 창은 최소화를 해제한다.

창 아래 또는 트레이 메뉴의 `도움말 / Wi-Fi 설정`을 누르면 기본 브라우저에서 한 페이지 사용 안내서를 연다.<br>
안내서는 앱에 포함되어 인터넷 없이 열리며 USB 최초 연결·Wi-Fi 설정·전원 공급·일반모드 설정·연결 문제 해결 방법을 설명한다.<br>
안내서의 `인쇄 / PDF 저장`으로 브라우저 인쇄 기능을 사용할 수 있다.

## 일반모드와 고급모드

창 위쪽의 `사용 모드`에서 일반모드와 고급모드를 선택하고 `설정 적용`을 누른다.<br>
새 설치는 일반모드로 시작하며 모드 항목이 없는 기존 설정은 고급모드로 불러온다.<br>
모드와 설정값은 앱을 다시 열어도 유지된다.

일반모드의 `간편 설정`에서는 다음 항목만 설정한다.

1. `자동 밝기 사용`을 선택하고 조명 ON 기준 조도와 ON·OFF 밝기를 입력한다.
2. 기준 조도 미만이면 OFF 밝기, 기준 이상이면 ON 밝기를 사용한다.
3. `자동 화면 꺼짐·켜짐 사용`을 선택하고 앉아 있을 때 거리 범위와 범위 밖에서 기다릴 시간을 입력한다.
4. `설정 적용`을 누른다.

일반모드는 유효한 거리가 착석 범위를 벗어난 시점부터 입력한 시간을 센다.<br>
예를 들어 기다릴 시간을 5초로 지정하면 범위 이탈 5초 뒤에 꺼짐 카운트다운을 시작하고, 다시 5초 뒤에 화면 끄기를 요청한다.<br>
일반모드는 최근 입력 뒤 30초 같은 추가 보호 시간이나 거리 유지 시간을 더하지 않는다.<br>
새 키보드·마우스 입력이 들어오면 이석 대기와 꺼짐 카운트다운을 취소하고 입력한 이석 대기 시간부터 다시 센다.<br>
거리 범위 안으로 돌아와도 대기를 취소하거나 화면 켜기를 요청한다.<br>
조명 밝기 전환에는 기본 1초 유지 시간을 사용하고 연결·오류 복구 후에는 정상 측정이 5초 이어져야 제어를 시작한다.<br>
거리가 측정되지 않아도 VL53L1X의 통신과 측정 갱신이 정상이면 부재 시간을 센다.<br>
통신·센서 고장·측정 만료·수신 중단·Windows 세션 확인 실패가 발생하면 자동 꺼짐을 보류한다.

고급모드에서는 조도 곡선·사용자 밝기 프로필·거리 이력·상태 전환 유지 시간·최근 입력 보호와 수동 모니터 시험을 설정할 수 있다.<br>
일반모드로 바꿔도 고급 옵션은 저장된 값으로 남고, 고급모드로 돌아가 적용하면 다시 사용한다.<br>
조도 기준·ON/OFF 밝기·착석 거리·부재 시간은 두 모드가 함께 사용하는 값이다.

두 모드 모두 창 맨 위에 자리 비움 대기와 화면 꺼짐 카운트다운을 표시하며 탭이나 스크롤 위치에 영향을 받지 않는다.<br>
카운트다운 중 키보드 입력·마우스 이동·클릭 또는 착석 재감지가 있으면 즉시 취소한다.<br>
자동 카운트다운을 새 입력으로 취소할 때는 15분 중단을 적용하지 않으며 이석 대기 시간부터 다시 측정한다.<br>
고급모드의 최근 입력 보호를 꺼도 새 입력에 따른 취소는 동작한다.<br>
수동 시험도 시작 이후 새 입력이나 새 착석 감지가 있으면 카운트다운을 취소한다.

마지막 5초에는 Windows에서 기본 모니터로 지정한 화면 중앙에 큰 숫자 `5 → 4 → 3 → 2 → 1`을 표시한다.<br>
카운트다운은 Windows 알림과 알림 소리 없이 표시한다.<br>
이 오버레이는 일반·고급 모드와 수동 시험에 공통으로 적용되며 앱을 트레이에 숨기거나 다른 프로그램을 사용 중이어도 맨 앞에 표시된다.<br>
현재 사용하는 프로그램의 키보드 포커스는 바꾸지 않으며 별도 작업 표시줄 버튼을 만들지 않는다.<br>
숫자 오버레이와 상단 상태 영역에는 꺼짐 취소 버튼을 표시하지 않고 입력·착석 감지로 해제한다.<br>
자동 꺼짐 중 다시 착석하거나 통신·센서 오류로 꺼짐이 보류되면 숫자를 숨긴다.<br>
카운트다운 종료나 앱 종료 때도 숫자를 숨기며 표시 때문에 기존 5초 시간이 늘어나지 않는다.<br>
밝기 제어 대상으로 선택한 모니터와 관계없이 숫자는 Windows 기본 모니터 중앙에 표시하고 화면 끄기 요청은 연결된 화면 전체에 적용한다.

## 센서 연결

1. [배선 안내](hardware.md)에 맞춰 BH1750·LD2412와 ESP32-S3를 연결한다.
2. [펌웨어 시험 안내](firmware-testing.md)에 따라 보드에 펌웨어를 기록한다.
3. 개발보드의 ESP USB 커넥터를 PC에 연결한다.
4. `자동 제어 / 센서` 탭에서 COM 포트를 선택하고 `연결`을 누른다.
5. 조도·인체 감지·움직임·정지·거리와 센서 유효성을 확인한다.

자동 탐색은 ESP USB 후보가 하나일 때 사용한다.<br>
여러 장치가 있으면 COM 포트를 지정하고 필요하면 USB 일련번호로 재연결 대상을 고정한다.<br>
포트 연결 후 펌웨어 식별과 센서 패킷을 확인하며 잘못된 장치는 연결 오류로 표시한다.<br>
케이블을 다시 연결하면 같은 프로그램에서 재연결을 시도한다.<br>
플래시·리셋·별도 센서 로그 도구를 실행하기 전 `연결 해제 / 플래시 준비`를 눌러 COM 포트를 비운다.<br>
포트가 닫히기 전에는 다른 도구가 같은 장치를 열 수 없다.

## 자동 밝기

### lux 구간별 사용자 프로필

`밝기 설정 / 프로필`에서 `사용자 프로필 · lux 구간별 밝기`를 선택한다.<br>
`새 프로필`로 만들거나 현재 프로필을 `복제`하고 이름을 지정한다.<br>
표에 기준 조도와 해당 기준 이상에서 사용할 밝기를 입력한다.<br>
기준이 여러 개이면 현재 조도 이하인 기준 중 가장 큰 값을 사용한다.

| 기준 조도 이상 | 밝기 | 적용 구간 |
|---|---|---|
| 0 lux | 2% | 0 이상, 100 lux 미만 |
| 100 lux | 30% | 100 이상, 300 lux 미만 |
| 300 lux | 55% | 300 lux 이상 |

첫 0 lux 구간은 모든 조도에 대응하기 위한 기본값이며 삭제하지 않는다.<br>
프로필과 프로필별 구간은 각각 최대 32개까지 만들 수 있다.<br>
기준 조도는 중복 없이 오름차순으로 입력하고 밝기는 0~100 정수를 사용한다.<br>
파란 점을 드래그하면 표의 기준 조도·밝기가 함께 바뀌며 인접 기준을 넘어가지 않는다.<br>
첫 점은 밝기만 바꿀 수 있다.

최신 정상 조도는 주황색으로 표시하고 `현재 조도로 구간 추가`로 기준을 만들 수 있다.<br>
센서 데이터가 만료되면 표시를 지우고 현재 조도 추가를 거부한다.<br>
그래프는 편집한 구간을 보여 주며 실제 모니터 밝기를 측정한 값이 아니다.<br>
입력 오류가 있으면 내용을 표시하고 적용·프로필 전환을 보류한다.

`전환 유지`는 새 조도 구간이 연속으로 유지돼야 하는 시간이며 기본 1초이다.<br>
`하강 이력`은 조도가 내려갈 때 추가로 낮아져야 하는 조도이며 기본 0 lux이다.<br>
예를 들어 기준이 100 lux이고 하강 이력이 5 lux이면, 위 구간에서 95 lux보다 낮아진 상태가 유지될 때 아래 구간으로 바뀐다.<br>
조도가 올라갈 때는 원래 기준인 100 lux 이상을 사용한다.<br>
이력 값은 가장 좁은 조도 구간의 폭보다 작게 입력하며 0으로 두면 이력을 사용하지 않는다.

`밝기 설정 적용`을 누르면 전체 프로필과 선택한 이름을 저장하고 자동 제어에 반영한다.<br>
앱을 다시 실행하면 저장한 프로필과 선택 상태를 읽는다.<br>
편집·이름 변경·프로필 선택만으로는 실제 밝기 명령을 보내지 않는다.<br>
프로필 전환 때 유효한 편집 내용은 유지되며 앱을 종료하기 전에는 적용을 눌러 저장한다.<br>
`자동 밝기`가 켜져 있고 센서 안정화·모니터 선택이 끝나면 지정한 밝기를 그대로 요청한다.<br>
이 방식은 EMA·곡선 보간·곡선 최소·최대 밝기·변경 최소 폭을 사용하지 않으며 명령 간격과 수동 조절 보호는 유지한다.

프리셋·계단형 그래프·하강 이력의 참고 자료는 [FanCtrl 자동 팬 제어 설명](https://github.com/lich426/FanCtrl/tree/master#auto-fan-control)과 [FanCtrl 설정 화면](https://user-images.githubusercontent.com/26077884/109588504-31e8bf80-7b4c-11eb-9cf9-4d6d43930383.png)이다.<br>
LumaSense의 프로필 편집기와 그래프는 PySide6로 구현한다.

### 두 가지 밝기와 연속 곡선

`밝기 설정 / 프로필`에서 `조명 ON/OFF · 두 가지 밝기`를 선택하고 기준 조도와 형광등 ON·불 끔 밝기를 지정한다.<br>
조도가 기준 이상이면 ON 밝기, 기준 미만이면 불 끔 밝기를 사용하며 같은 쪽에서 기본 1초 유지될 때 전환한다.<br>
이 방식은 두 밝기값을 그대로 전송하며 조도에 따른 중간 밝기를 만들지 않는다.<br>
곡선용 최소·최대 밝기 제한을 사용하지 않으므로 불 끔 밝기를 2%로 지정하면 2%를 요청한다.

조도 센서의 위치와 방향을 고정하고 형광등을 켠 상태에서 ON 밝기를 미리 본 뒤 `형광등 ON 현재 조도 기록`을 누른다.<br>
불을 끈 뒤 불 끔 밝기를 미리 보고 `불 끔 현재 조도 기록`을 누른다.<br>
최신 정상 조도 데이터가 없으면 기록하지 않으며 기록한 조도와 시각을 표시한다.<br>
ON 기록이 OFF 기록보다 높을 때 `두 조도 기록의 중간값을 기준으로 사용`으로 기준을 계산하거나 직접 기준 조도를 입력한다.<br>
`밝기 설정 적용`을 누르면 두 밝기·기준·조도 기록을 설정 파일에 저장한다.<br>
두 조도의 차이가 작거나 기록 순서가 뒤바뀌면 센서가 가려졌는지와 실제 조명 상태를 확인하고 다시 기록한다.

`조도 곡선 · 연속 밝기`를 선택하면 Lux 오름차순의 점 사이를 선형 보간하고 양끝 밖에서는 끝점 값을 사용한다.<br>
이 방식의 밝기 상·하한, 전환 시간 1~3초, EMA 반영 비율과 명령 최소 간격은 `자동 제어 설정`에서 조절한다.<br>
EMA 값이 클수록 새 조도값을 빠르게 반영하며 큰 조도 변화는 목표에 바로 반영한다.<br>
명령 최소 간격과 변경 최소 폭을 늘리면 작은 반복 변경이 줄어든다.

대시보드의 `자동 밝기`를 선택하고 `설정 적용`을 누른다.<br>
센서 안정화와 대상 모니터 선택이 끝나면 밝기 명령을 전송한다.<br>
표시하는 요청 밝기는 프로그램이 보낸 값이며 실제 휘도 측정값이 아니다.<br>
미리보기·트레이 슬라이더·수동 시험 화면에서 밝기를 바꾸면 자동 밝기를 기본 900초 중단한다.<br>
전체 자동 제어 일시 중단은 밝기와 절전 모두에 적용되며 `자동 제어 재개`로 해제한다.

자동 밝기 명령이 접수되면 약 2초 뒤 Twinkle Tray 보고값을 조회하고, 일치하면 요청 후 약 8초에 다시 확인한다.<br>
이후에는 자동 제어 조건이 유지되는 동안 30초 간격으로 보고값을 확인한다.<br>
보고값이 요청값과 다르면 현재 조도와 목표 밝기를 다시 확인한 뒤 최소 2초를 두고 재시도하며, 설정한 명령 최소 간격도 지킨다.<br>
같은 목표 밝기에서는 최초 요청 외에 최대 2회만 재시도하고, 계속 다르면 `재시도 종료`를 표시한다.<br>
보고값을 읽지 못하면 밝기 명령을 재전송하지 않고 조회만 최대 2회 추가 시도한다.<br>
목표 밝기·설정·대상 모니터가 바뀌거나 화면 복귀·자동 제어 재개가 이루어지면 확인과 재시도 횟수를 새로 관리한다.<br>
화면 복귀 요청이 접수되면 최소 2초를 기다린 뒤 최신 조도에 맞는 밝기를 다시 요청한다.<br>
센서 안정화·잠금 해제·자동 제어 활성화·수동 밝기 보호 등 실행 조건이 충족되어야 재적용과 재확인을 진행한다.

일반모드의 조명 설정 아래와 `연결 / 상태`의 현재 상태에 Twinkle Tray 보고값과 확인 상태를 표시한다.<br>
보고값 일치는 Twinkle Tray가 반환한 값의 일치이며 실제 화면 밝기 변화는 화면에서 따로 확인한다.<br>
실행 대기 중 조도 판정이 바뀌거나 센서·수동 조절·잠금·절전 조건이 바뀌면 이전 요청을 취소한다.<br>
자동 밝기 로그에는 판단·실행 시점의 조도와 센서 순번, 목표값·요청값·보고값·재시도 상태를 기록한다.<br>
로그 파일 교체나 저장에 실패하면 오류를 별도 이벤트와 밝기 확인 상태에 표시한다.<br>
파일 교체만 실패한 경우에는 기존 파일에 계속 기록하므로 파일 크기가 회전 기준을 넘을 수 있다.

미리보기 진행·요청 접수·오류는 탭과 스크롤 위치에 관계없이 창 위에 표시한다.<br>
모니터 목록이 준비되지 않았으면 다시 조회하고, 저장된 대상 모니터를 확인한 뒤 밝기를 요청한다.<br>
Twinkle Tray가 빈 목록을 반환하면 조회만 최대 3회 시도하며 미리보기의 밝기 변경 명령은 자동 재전송하지 않는다.<br>
앱 시작 시 모니터 목록이 계속 비어 있으면 5초, 15초, 30초 뒤 자동으로 다시 검색한다.<br>
검색을 기다리는 동안에는 밝기를 변경하지 않으며 마지막 검색도 실패하면 오류를 표시한다.<br>
`모니터 선택 / 탐색`을 눌러 직접 검색하면 예약된 자동 검색은 취소된다.<br>
저장된 대상이 없거나 현재 연결에서 찾지 못하면 `모니터 선택 / 탐색`에서 대상을 선택한 뒤 미리보기를 다시 누른다.<br>
요청 접수는 Twinkle Tray 응답이며 실제 화면 밝기 변화는 따로 확인한다.

## 자동 절전과 복귀

고급모드의 `자동 제어 설정`에서 연속 부재 시간과 PC 감지 범위, 최근 입력 뒤 추가 보호 시간을 지정한다.<br>
PC 감지 범위는 수신 거리의 판정 조건이며 레이더에 저장되는 거리문 설정과 별개이다.<br>
대시보드에서 자동 절전·복귀를 선택하고 `설정 적용`을 누른다.<br>
정상 센서가 기본 30초 연속 부재를 보고하고 최근 입력이 없으면 5초 취소 카운트다운을 시작한다.<br>
추가 입력 보호를 켠 경우 해당 시간이 지난 뒤 부재 시간을 다시 측정하며, 이 옵션과 관계없이 새 입력은 진행 중인 대기·카운트다운을 취소한다.<br>
레이더의 부재 유지 시간이 5초인 구성에서 앱 연속 부재 20초·최근 입력 보호 5초를 사용하면 이석 뒤 약 30초에 절전을 요청한다.<br>
이 시간에는 레이더의 5초, 앱의 20초와 취소 카운트다운 5초가 포함되며 중간 재감지나 새 입력이 있으면 다시 측정한다.<br>
`15분 일시 중단 / 절전 취소` 버튼이나 트레이 메뉴의 `카운트다운 취소`를 눌러 취소할 수 있다.<br>
자동 절전 체크를 해제하면 즉시 비활성화된다.<br>
센서 오류·데이터 만료·연결 중단·안정화 중에는 새 자동 절전을 요청하지 않는다.<br>
Windows 잠금이나 입력 상태를 확인하지 못해도 절전을 보류한다.

대시보드의 `존재 상태 / 화면 요청`에는 최근 입력 보호와 연속 부재 확인의 남은 시간이 표시된다.<br>
`Windows 입력 상태 확인 불가`는 입력 조회 실패이며 최근 입력 보호 대기와 구분한다.<br>
연결 직후나 센서 오류 복구 중에는 `센서 안정화 대기`가 표시된다.<br>
센서 거리·입력 경과 시간·안정화 상태·적용 거리 범위는 상태가 바뀔 때 `presence_state` 로그에 함께 기록된다.

VL53L1X는 `ToF 착석 최소 거리`와 `ToF 착석 최대 거리`로 착석을 판정하며 `PC 감지 범위`는 적용하지 않는다.<br>
센서가 천장을 향해도 유효한 거리가 착석 범위 밖이면 부재로 판정하며, 통신과 측정 갱신이 정상인 거리 측정 실패도 부재 판정한다.<br>
거리 측정 실패는 `거리 미측정 · 부재 판정`으로 표시하고 카운트다운을 진행하며 통신·측정 갱신 중단과 명시적인 센서 고장은 꺼짐을 보류한다.<br>
고급모드에서 최근 입력 보호 30초·연속 부재 5초를 적용하면 마지막 입력 직후 자리를 비운 뒤 약 40초에 화면 절전을 요청한다.<br>
이 시간에는 입력 보호 30초와 부재 확인 5초, 취소 카운트다운 5초가 포함되며 센서 안정화·측정 실패·재감지·새 입력이 있으면 더 늦어지거나 보류된다.

재감지하거나 자동 제어를 중단하면 프로그램이 요청한 절전을 복귀시킨다.<br>
자동 복귀에는 별도 대기 시간을 더하지 않으며 실제 화면이 켜지기까지의 시간은 모니터에서 확인한다.<br>
자동 복귀 방식은 `ExecutionState 우선`, `SC_MONITORPOWER 우선`, 별도 허용한 `마우스 이동` 중에서 선택한다.<br>
API 호출이 실패하면 다른 API를 시도하며 정상 반환만으로 실제 화면 켜짐을 확정하지 않는다.<br>
GUI가 정지하거나 종료되면 독립 감시 프로세스가 정상 신호 만료 후 복귀를 시도한다.<br>
복귀 요청 이후에도 화면이 켜지지 않으면 마우스나 키보드로 직접 복귀하고 로그와 관찰을 함께 확인한다.

`수동 모니터 시험`의 복귀 지연·추가 복귀 간격은 API를 구분해서 시험할 때 사용하는 별도 설정이다.<br>
각 API의 단독 성공 여부는 추가 요청 전에 화면이 켜졌는지 확인한다.<br>
자세한 순서는 [화면 시험 안내](testing.md)를 따른다.

## 레이더 설정

`시스템 / 레이더`의 공학 모드는 움직임·정지 에너지 진단에 사용한다.<br>
거리문·유지 시간과 민감도는 각각 전송 체크를 선택한 경우에만 레이더 설정 명령에 포함한다.<br>
거리문은 레이더 프로토콜의 0~13 인덱스이며 센티미터 단위가 아니다.<br>
정확한 거리문 길이는 장치 해상도에 따라 해석한다.<br>
움직임·정지 임계값은 각 거리문마다 0~100으로 입력한다.<br>
표시값은 편집 중인 요청값이며 레이더에서 읽은 현재값이 아니다.<br>
전송 버튼을 누른 뒤 ACK 성공·실패를 확인한다.<br>
저장되는 설정은 오류가 발생해도 자동 재전송하지 않는다.<br>
부분 적용 오류가 표시되면 이전 설정이 모두 유지됐다고 가정하지 말고 센서 동작을 확인한 뒤 필요한 항목을 다시 전송한다.

## 프로필과 로그인 실행

설정 내보내기는 일반·고급 모드와 밝기 방식·전체 사용자 밝기 프로필·선택한 이름·ON/OFF 조도 기록과 밝기·밝기 곡선·센서 연결·자동 제어·수동 시험·레이더 요청값을 JSON으로 저장한다.<br>
가져오기는 편집 상태로 열며 확인 후 `설정 적용`으로 반영한다.<br>
프로필의 모니터가 현재 목록에 없으면 실제 연결된 대상을 다시 선택한다.<br>
레이더 요청값을 프로필에서 불러오거나 적용해도 장치에 자동 전송하지 않는다.<br>
`시작 시 센서 자동 연결`, `Windows 로그인 시 트레이로 실행`은 시스템 화면에서 선택한다.<br>
Windows 로그인 시에는 트레이로 실행하고 실행파일을 직접 열면 일반 창을 표시한다.<br>
로그인 실행은 현재 사용자 계정의 Run 레지스트리에 등록하며 관리자 권한이 필요하지 않다.<br>
배포 폴더를 이동한 경우 로그인 실행을 해제·적용한 뒤 다시 선택·적용해 경로를 갱신한다.<br>
폴더를 삭제하기 전 로그인 실행을 해제한다.

## 시뮬레이션과 로그

시스템 화면의 `별도 시뮬레이션 창 열기` 또는 다음 명령으로 가상 센서를 사용한다.

```powershell
.\LumaSense.exe --simulate
```

가상 Lux·정지·움직임·부재·센서 오류를 바꾸고 자동 제어 상태와 취소를 확인한다.<br>
시뮬레이션에서는 실제 USB 연결·레이더 설정·밝기·전원 API를 호출하지 않는다.<br>
시뮬레이션의 설정과 로그는 실제 실행과 분리한 `simulation` 폴더에 저장한다.

기본 데이터 폴더는 `%LOCALAPPDATA%\SmartMonitorController`이며 창의 `로그 폴더 열기`로 연다.<br>
`settings.json`은 설정, `sensor.jsonl`과 회전 파일은 원본 센서 데이터, `events-날짜.jsonl`은 제어·오류 이벤트이다.<br>
`app.log`는 크기에 따라 회전하며 이벤트 로그는 UTC 날짜별 파일에 저장된다.<br>
이벤트 로그의 장기 보관 용량은 사용자가 관리한다.<br>
API 접수 결과와 실제 화면 관찰 결과는 별도로 기록한다.

## 코드와 자동 검사

SerialManager는 연결·재연결·ACK, SensorManager는 패킷 유효성과 안정화를 담당한다.<br>
BrightnessController와 PresenceController는 밝기 계산·존재 상태를 관리하고 AutomationRuntime이 작업 실행 조건을 다시 검사한다.<br>
MainWindow는 Qt 신호로 센서 상태를 전달받고 별도 작업 풀에서 밝기·전원 명령을 실행한다.<br>
독립 복귀 프로세스는 `watchdog.py`와 `lease_guard.py`에 있다.<br>
실행·빌드·장시간 검사 명령은 [배포와 검증 안내](release-testing.md)를 따른다.
