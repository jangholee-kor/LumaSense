# SuperMini S3 Wi-Fi 송신 출력 조사 기록

## 조사 범위와 결론

2026-11-03 기준으로 내장 안테나형 ESP32-S3 SuperMini의 높은 Wi-Fi 송신 출력과 접속 실패 사이의 관련 사례를 조사했다.<br>
조사 대상 소스는 `c21b83c`이며 Windows 앱 0.7.4·센서 펌웨어 0.3.1·ESP-IDF 5.5.4를 기준으로 확인했다.

송신 출력을 낮춰 접속 문제가 개선됐다는 보고는 있지만, 사용자의 S3 SuperMini에서 같은 문제가 발생하는지는 확인하지 않았다.<br>
C3 SuperMini 사례와 다른 제조사의 S3 보드 사례를 사용자 보드의 확정 결함이나 ESP32-S3 전체의 공통 소프트웨어 버그로 해석하지 않는다.<br>
출력 제한은 비교 시험할 수 있는 우회 방법이며 안테나 설계·실장 상태·전원 문제의 원인을 확정하거나 하드웨어를 수리하는 방법은 아니다.

## 현재 펌웨어에서 확인한 내용

[`smc_network_init()`](../../firmware/main/smc_network.c)은 `esp_wifi_start()`를 호출하지만 `esp_wifi_set_max_tx_power()`로 출력을 별도 제한하지 않는다.<br>
조사한 로컬 SuperMini 빌드의 `.local/firmware-build-supermini/config/sdkconfig.h`에는 `CONFIG_ESP_PHY_MAX_WIFI_TX_POWER=20`과 `CONFIG_ESP_PHY_MAX_TX_POWER=20`이 생성돼 있었다.<br>
이는 빌드 설정의 최대 출력 상한이며 실물에서 읽은 현재 설정값이나 실제 방사 출력 측정값은 아니다.<br>
드라이버·PHY·통신 속도·국가 설정에 따른 제한을 구분해야 하며 모든 패킷을 항상 20 dBm으로 송신한다는 뜻도 아니다.

Windows 앱에는 송신 출력 조절 항목이 없다.<br>
PC 앱만 업데이트해도 센서의 출력이 낮아지는 것은 아니며, 조정하려면 S3 펌웨어에서 제한을 적용해야 한다.

## 제안한 설정과 적용 위치

집 공유기와 가까운 설치 환경에서 우선 15 dBm으로 제한해 비교하고 접속이 불안정하면 11 dBm, 8.5 dBm 순으로 시험하는 방안을 제안했다.<br>
이 값은 시험 시작점이며 사용자의 보드에서 검증된 최적값은 아니다.<br>
출력을 낮추면 통신 거리가 줄어들 수 있으므로 접속 여부뿐 아니라 실제 설치 위치에서 센서 수신이 유지되는지도 확인한다.

| 시험 순서 | 최대 출력 설정 요청 | `esp_wifi_set_max_tx_power()` 인수 |
|---|---|---|
| 1 | 15 dBm | `60` |
| 2 | 11 dBm | `44` |
| 3 | 8.5 dBm | `34` |

인수의 단위는 0.25 dBm이며 드라이버가 지원하는 단계로 매핑된다.<br>
적용 시에는 `esp_wifi_start()`가 성공한 뒤 첫 `esp_wifi_connect()` 요청 전에 제한하고, 반환값과 `esp_wifi_get_max_tx_power()`로 읽은 값을 확인한다.<br>
조회값은 드라이버의 최대 출력 설정이며 RF 계측기로 측정한 방사 출력과 구분한다.<br>
숫자를 코드에 고정하기보다 보드별 빌드 설정으로 분리하면 SuperMini와 기존 DevKit을 독립적으로 조정할 수 있다.

```c
/* 적용 방법 예시이며 현재 펌웨어에 추가된 코드는 아니다. */
esp_err_t result = esp_wifi_set_max_tx_power(60);  /* 15 dBm 설정 요청 */
/* result와 esp_wifi_get_max_tx_power() 조회 결과를 확인한다. */
```

## 실물 비교 시험 방법

1. 같은 공유기·보드 위치·케이블·전원으로 기준 조건을 고정한다.
2. 제한 전 설정과 15 dBm 설정을 비교하고, 필요할 때 11 dBm·8.5 dBm을 추가한다.
3. 전원을 여러 번 다시 넣어 공유기 접속·IP 할당·앱의 TCP 인증과 정상 센서 수신을 각각 확인한다.
4. 예를 들어 전원 재인가 10회와 연속 수신 10분을 기록하되 이 결과를 장시간 안정성 검증과 동일하게 취급하지 않는다.
5. 연결 실패·끊김과 보드 재부팅을 구분하고 각 출력 설정의 접속 성공 횟수·접속 시간·수신 중단 횟수를 비교한다.
6. 최종 설치에서는 모니터 USB 대기 전원과 화면이 꺼진 동안의 무선 수신도 확인한다.

출력 비교 중에는 공유기 채널·전원·안테나 주변 배치를 동시에 바꾸지 않아야 결과를 해석할 수 있다.<br>
문제가 남으면 전원 공급과 안테나 주변 금속·배선·공유기 설정을 별도 조건으로 확인한다.
