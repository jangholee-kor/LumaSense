  • USB 데이터 케이블과 집 공유기의 이름·비밀번호를 준비합니다.
  • 센서와 PC는 서로 통신할 수 있는 같은 집 내부 네트워크에 연결합니다.

무선은 데이터 전송 방식입니다.
S3에는 계속 전원이 필요하고, PC에서는 LumaSense가 실행 중이어야 합니다.

02집에서 Wi-Fi 설정하기

  1. 먼저 센서를 PC USB에 연결합니다

    일반 → 연결 / 상태

    연결 방식: USB를 선택합니다.
    포트 새로고침을 누르고 S3의 COM 포트를 선택한 뒤 연결을 누릅니다.
    COM 번호는 PC나 USB 포트에 따라 달라지므로 현재 표시된 번호를 사용합니다.
    조도·거리가 들어오고 센서가 정상인지 확인합니다.

  2. 집 공유기 정보를 저장합니다

    시스템 / 센서 → SuperMini Wi-Fi 설정 · 먼저 USB로 연결

    2.4GHz 공유기 이름과 공유기 비밀번호를 입력합니다.
    USB로 Wi-Fi 설정 저장을 누르고 저장 응답을 확인합니다.
    공유기 이름은 UTF-8 기준 1~32바이트, 비밀번호는 8~63바이트이며 WPA2 비밀번호 방식으로 연결합니다.
    무선 장치 키는 비어 있으면 앱에서 자동으로 만들어 저장합니다.
    저장 후 비밀번호 입력칸이 비워지는 것은 정상입니다.

  3. 센서의 IP를 확인합니다

    시스템 / 센서 → 장치 IP / 연결 상태 조회

    잠시 기다렸다가 장치 IP / 연결 상태 조회를 누릅니다.
    공유기 연결됨과 IP 주소가 표시되면 공유기 접속이 완료된 것입니다.
    아직 IP가 없다면 잠시 후 다시 조회합니다.
    확인된 IP는 연결 화면의 센서 IP 입력칸에도 자동으로 들어갑니다.

  4. USB 데이터 연결을 해제합니다

    연결 / 상태 → 연결 해제 / 플래시 준비

    연결 해제 / 플래시 준비를 누르고 기존 연결이 종료될 때까지 기다립니다.
    무선 연결을 확인하는 동안에는 PC에 꽂힌 USB를 그대로 두어 전원을 공급해도 됩니다.

  5. 연결 방식을 Wi-Fi로 바꿉니다

    연결 / 상태 → 연결 방식: Wi-Fi · TCP

    Wi-Fi · TCP를 선택하고 센서 IP와 자동 저장된 무선 장치 키를 확인합니다.
    연결을 누른 뒤 조도·거리가 계속 갱신되는지 확인합니다.
    고급모드의 대시보드에서도 같은 연결을 설정할 수 있습니다.

    항목입력할 값
    센서 IP장치에서 조회한 IPv4 주소
    예: 192.168.0.50 — 실제 조회값으로 바꿉니다.
    TCP 포트47653 · 일반모드에서는 표시하지 않습니다.
    무선 장치 키USB로 Wi-Fi 설정을 저장할 때 만든 값
    공유기 비밀번호와 다른 값이며 임의로 바꾸지 않습니다.

  6. USB를 전원용 포트로 옮깁니다

    무선 수신을 확인한 뒤 S3를 모니터 USB나 별도 USB 전원에 연결합니다.
    보드가 다시 켜지고 공유기에 접속하면 앱이 재연결을 시도합니다.
    시스템 / 센서에서 시작 시 센서 자동 연결을 선택하고 시스템 설정 적용을 누르면 다음 실행에도 저장된 Wi-Fi 연결을 시도합니다.

모니터 USB를 쓴다면 대기 전원을 확인하세요.
화면이 꺼질 때 USB 전원도 끊기면 센서가 꺼져 착석을 감지할 수 없습니다.
모니터 설정에서 USB 대기 전원을 유지하거나 별도 USB 전원을 사용합니다.

03USB로 다시 사용하기

무선 연결 중이라면 연결 해제 / 플래시 준비를 누르고 종료를 기다립니다.
S3를 데이터 케이블로 PC에 연결한 뒤 연결 방식: USB와 COM 포트를 선택하고 연결을 누릅니다.
센서에 저장한 공유기 정보는 그대로 남아 있어 나중에 Wi-Fi로 돌아갈 수 있습니다.

USB 사용

PC USB 한 가닥으로 전원과 데이터를 함께 연결합니다.
센서 IP나 무선 장치 키를 입력하지 않습니다.

Wi-Fi 사용

USB는 전원 공급에 사용하고 데이터는 공유기를 통해 전송합니다.
공유기 정보를 바꿀 때는 PC에 USB로 연결해 다시 저장합니다.

04밝기와 자리 비움 설정

사용 모드: 일반 → 간편 설정

조명에 맞춰 밝기 바꾸기

자동 밝기 사용을 켜고 조명 ON 기준 Lux와 두 가지 밝기를 입력한 뒤 설정 적용을 누릅니다.
기준 이상이면 조명이 켜졌을 때 밝기를, 기준 미만이면 조명이 꺼졌을 때 밝기를 사용합니다.
밝아질 때와 어두워질 때 모두 같은 상태가 1초 유지되면 목표 밝기를 요청합니다.
모니터 반영에는 센서 수신과 모니터 처리 시간이 더해집니다.

자동 밝기 요청 후 약 2초에 Twinkle Tray 보고값을 확인하고, 일치하면 요청 후 약 8초에 다시 확인합니다.
이후에는 자동 제어 조건이 유지되는 동안 30초 간격으로 조회합니다.
보고값이 다르면 최신 조도와 제어 조건을 확인하고 최소 2초와 설정한 명령 최소 간격을 지켜 재시도합니다.
같은 목표 밝기의 재시도는 최초 요청 외에 최대 2회이며, 계속 다르면 조명 설정 아래에 재시도 종료를 표시합니다.
보고값을 읽지 못할 때는 밝기를 재전송하지 않고 조회만 최대 2회 추가 시도합니다.
목표 밝기·설정·대상 모니터 변경, 화면 복귀 또는 자동 제어 재개 시 확인 횟수를 새로 관리합니다.
화면 복귀 요청 후에는 최소 2초를 기다리고 최신 조도로 밝기를 다시 적용하며, 수동 밝기 보호와 센서·잠금·절전 조건을 지킵니다.
표시하는 보고값은 Twinkle Tray의 응답이며 실제 화면 밝기는 따로 확인합니다.
실행 전에 조도 판정이나 제어 조건이 바뀌면 이전 요청을 취소합니다.

밝기 로그에는 판단·실행 시점의 조도와 목표·요청·보고값을 함께 기록합니다.
로그 파일 교체나 저장에 실패하면 밝기 확인 상태에 오류를 표시합니다.
파일 교체만 실패하면 기존 파일에 계속 기록하므로 파일 크기가 회전 기준을 넘을 수 있습니다.

예: 기준 100 Lux · 조명 ON 22% · 조명 OFF 5%
이 값은 예시입니다.
조명을 켠 상태와 끈 상태의 현재 조도를 확인하고 기준을 그 사이에 정하세요.

자리 비우면 화면 끄기

센서가 앉아 있는 몸통을 향하도록 설치하고 현재 거리를 확인합니다.
자동 화면 꺼짐·켜짐 사용을 켜고 앉아 있을 때 거리 범위와 범위 밖에서 기다릴 시간을 입력한 뒤 설정 적용을 누릅니다.

착석 범위 이탈 → 설정한 대기 시간 → 5초 카운트다운 → 화면 끄기 요청 대기 시간을 5초로 입력했다면 범위 이탈 후 약 10초 뒤에 끄기를 요청합니다.
  • 카운트다운은 기본 모니터 중앙에 큰 숫자로 표시됩니다.
  • 카운트다운은 Windows 알림과 알림 소리 없이 표시됩니다.
  • 새 키보드·마우스 입력이나 착석 재감지가 있으면 대기·카운트다운을 취소합니다.
  • 일반모드에서 새 입력으로 취소하면 설정한 대기 시간부터 다시 셉니다.
  • 꺼진 뒤 다시 착석하거나 키보드·마우스를 사용하면 화면 켜기를 요청합니다.
  • 센서 통신이 정상이면 거리가 측정되지 않는 상태도 부재로 판단합니다.
    연결 끊김·센서 고장·데이터 갱신 중단은 자동 꺼짐을 보류합니다.

VL53L1X는 거리로 착석 여부를 판단합니다.
사람과 의자·벽 같은 물체를 구분하지 않으므로 빈 의자가 착석 범위 안에 잡히지 않게 각도와 범위를 조절하세요.
밝기는 선택한 모니터에 적용하고, 화면 끄기 요청은 연결된 화면 전체에 적용합니다.

06연결이 안 될 때

공유기 연결됨이나 IP가 표시되지 않아요

USB 연결이 유지되는지 확인하고 공유기 이름과 비밀번호를 다시 확인합니다.
2.4GHz 네트워크와 WPA2 비밀번호 방식을 사용합니다.
공유기는 WPA2 개인 네트워크 또는 WPA2 호환 모드로 설정합니다.
5GHz 전용이나 비밀번호 없는 네트워크는 이 설정 방식으로 연결할 수 없습니다.
설정을 저장한 뒤 잠시 기다렸다가 IP를 다시 조회합니다.

IP는 있는데 무선 연결이 안 돼요

기존 USB 연결을 먼저 해제했는지 확인합니다.
센서 IP와 무선 장치 키, TCP 포트 47653을 확인합니다.
PC와 센서를 같은 내부 네트워크에 연결하고 게스트 Wi-Fi나 장치 간 통신 차단 설정을 확인합니다.
공유기의 포트 포워딩은 필요하지 않습니다.
PC 보안 프로그램의 연결 차단 여부도 확인합니다.

어제는 됐는데 오늘은 연결이 안 돼요

센서 전원을 확인하고 USB로 연결해 IP를 다시 조회합니다.
공유기가 센서에 다른 IP를 할당했다면 앱의 센서 IP를 새 값으로 바꿉니다.
공유기에서 해당 센서의 DHCP 주소 예약을 설정하면 같은 IP를 유지하기 편합니다.

새 PC에서 무선 장치 키가 없어요

새 PC에 센서를 USB로 연결하고 Wi-Fi 설정을 다시 저장합니다.
장치 키가 비어 있으면 새 키를 생성하며, 기존 PC에서 연결하려면 같은 키를 사용해야 합니다.
설정 내보내기 파일에는 무선 장치 키가 포함되지 않습니다.

앉아 있어도 화면이 꺼지거나, 떠나도 안 꺼져요

센서 각도와 현재 거리, 착석 범위를 확인합니다.
빈 의자나 벽이 범위 안에 잡히면 계속 착석으로 판단할 수 있습니다.
상단에 센서 확인 중·자동 꺼짐 보류가 표시되면 연결과 센서 상태를 먼저 확인합니다.
연결·오류 복구 뒤에는 정상 측정이 5초 이어진 후 자동 제어를 시작합니다.

화면이 꺼지면 센서도 같이 꺼져요

모니터 USB의 대기 전원이 끊긴 상황일 수 있습니다.
모니터의 USB 대기 전원 설정을 확인하거나 전원이 유지되는 별도 USB 포트·전원을 사용합니다.

USB COM 포트가 안 보이거나 연결이 안 돼요

충전 전용 케이블 대신 데이터 케이블을 사용하고 PC USB에 직접 연결합니다.
포트 새로고침을 누르고 현재 S3의 COM 포트를 선택합니다.
보드 기록 도구나 다른 시리얼 프로그램이 포트를 사용 중이면 종료합니다.
